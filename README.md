# FixTrack

FixTrack is a Python app that helps computer repair technicians log repair jobs and track their progress.

## Planned features

- Add, view, search, and update repair jobs.
- Record the device name, issue, date, and repair notes.
- Mark each job as Waiting, In Progress, or Completed.
- Save repair records in a JSON file so they are available the next time the app opens.
